# Public download stats

Public, aggregate installer download statistics for AITuberFlow.

Generated from GitHub Release asset `download_count` values. These counts are already public via the GitHub API; this directory stores a small presentation-friendly summary for charts and badges.

Included:

- latest release tag
- total installer downloads
- platform totals for Windows x64, macOS Apple Silicon, and macOS Intel
- append-only platform history when counts change

Not included:

- IP addresses
- referrers
- countries
- user agents
- Cloudflare analytics logs
- per-user or raw access logs
